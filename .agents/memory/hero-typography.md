---
name: Tipografia do hero
description: Preferência visual para os textos principais do portfólio.
---

Quando o usuário pedir para aumentar os textos do hero, o aumento precisa ser claramente perceptível. Ajuste a largura do texto junto com o tamanho da fonte para manter quebras legíveis em telas pequenas e grandes.

**Why:** o primeiro aumento pareceu sutil demais para o usuário, que pediu uma mudança mais evidente para preencher o espaço vazio.

**How to apply:** confira o hero em celular e desktop; evite que as palavras ultrapassem as margens ou quebras deixem uma palavra isolada sem intenção.
